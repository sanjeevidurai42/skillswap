Prototype Development Lab Project

SkillSwap – Collaborative Learning Through Hybrid Recommendation

An academic engineering project demonstrating reciprocal peer education, Scikit-Learn TF-IDF semantic vectorization, and resilient full-stack service architecture.

Designed & Developed by: Sanjeeviraj

Project Objective & Problem Statement

The Challenge

In academic institutions, students frequently struggle to find personalized mentorship in specialized engineering and design topics. Private tutoring services are cost-prohibitive, while traditional static forums lack structured bilateral matching where both parties mutually gain skills.

The SkillSwap Solution

SkillSwap eliminates monetary barriers by creating a reciprocal skill exchange ecosystem. A student skilled in Python programming can mentor another student in exchange for learning UI/UX design or DevOps pipelines, orchestrated by an intelligent hybrid matching engine.

The Python Hybrid Recommendation Algorithm

FastAPI Microservice

Our recommendation engine addresses the cold-start problem and reciprocal imbalance by fusing four normalized signals into a composite compatibility score:

MatchScore = (0.50 × SkillScore) + (0.25 × TextSimilarity) + (0.15 × ScheduleOverlap) + (0.10 × FormatSynergy)

1. Skill Compatibility (50%)

Evaluates bidirectional symmetry: whether Candidate teaches what Current User wants to learn ($A \rightarrow B$) and vice versa ($B \rightarrow A$).

2. TF-IDF Text Sim (25%)

Vectorizes biography and skill goals with Scikit-Learn's TfidfVectorizer, calculating Cosine Similarity across semantic profiles.

3. Schedule Overlap (15%)

Calculates Jaccard intersection of availability time slots (weekdays evening, weekends flexible).

4. Format Synergy (10%)

Ensures session medium alignment (Online vs In-Person campus labs vs Flexible).

Technology Implementation

  • Frontend: Semantic HTML5, CSS3 Custom Properties, Vanilla JavaScript (Framework-free, 100% standard web API).
  • Backend REST API: Node.js & Express.js with JWT authentication, HTTP-only cookies, rate limiting, and centralized error handling.
  • Database & Models: MongoDB with Mongoose schemas, text search indexing, and referral integrity.
  • Recommendation Engine: Python FastAPI microservice, Scikit-Learn TF-IDF, Cosine Similarity, and NumPy.
